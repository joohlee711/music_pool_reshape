PC ↔ USB 대조

PC rekordbox 컬렉션(XML)과 USB의 export.pdb를 비교해서 한쪽에만 있는 곡을 찾아줘. XML은 rekordbox에서 파일 → 내보내기 → 컬렉션을 xml 형식으로 내보내기로 만들어서 레포 rekordbox_xml/YYYYMMDD.xml로 올리면 돼. USB는 usb_pdb/YYYYMMDD/. 둘 다 가장 최근 날짜 걸 자동으로 읽어.

또는 여기로 끌어다 놓기 직접 연 XML은 이 브라우저 안에서만 읽고 어디에도 업로드하지 않아. 새로고침하면 다시 레포 최신본으로 돌아가.

최신 파일 찾는 중…

숨기기 필터는 플레이리스트 경로 중 하나라도 해당 이름(REF / _OLD / 하이퍼)이 들어가면 숨겨. CSV는 지금 보이는 목록 그대로 저장돼.

PC 컬렉션에서 빠진 곡이야. relocate가 안 됐거나 PC에서 지운 곡일 수 있어.
